## 真的出现优惠码后，怎么确认它不是“标题党”？

DMIT 的优惠码通常不应该只看“输入后有折扣”这一件事。

下单前至少核对这几项：

1. **产品范围**：LAX、HKG、TYO 是否全部适用，还是只限某一个机房。
2. **线路**：Premium、Eyeball、Tier 1 是否都参加。
3. **计费周期**：月付、季付、半年付、年付是否有不同折扣。
4. **循环折扣**：是首期优惠，还是续费时也保持折扣。
5. **特殊套餐排除**：限量套餐、促销套餐经常不能与普通折扣同时使用。
6. **账户金返还**：返的是账户余额，不等于即时现金折扣。
7. **退款规则**：参加活动后是否仍然适用普通退款规则。
8. **IPv4 等附加费用**：优惠是否只覆盖基础 VPS 价格。

2025 年圣诞活动就是一个很好的例子。官方明确区分了 10% 循环折扣、15% 循环折扣以及 5% / 10% 账户金返还，而且优惠针对不同产品范围。

所以看到“最高 25%”时，不应该直接理解成“结账时立减 25%”。它可能是折扣和未来账户金返还的组合。
